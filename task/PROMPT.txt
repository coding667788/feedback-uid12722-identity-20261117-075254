实现一个多租户ABAC授权服务，策略、用户属性和资源属性都带单调版本号，数据保存在本地SQLite。

请从空目录实现以下可运行工具。环境为 Windows、Python 3.12、仅CPU；不使用Docker或真实外部服务。除题面明确允许的cryptography外只用标准库。输入样例、模拟组件和测试数据由你在项目内构造，不存在另行提供的附件。

核心要求：
1. 策略支持eq、in、lt、AND、OR、NOT，值仅字符串、整数和集合。缺失属性采用三值逻辑：NOT unknown仍为unknown，AND含false为false，OR含true为true，剩余按unknown传播；只有明确true才算命中，命中deny优先，默认拒绝。
2. 每次判定从同一数据库快照读取策略与属性，返回判定、匹配规则及三个版本。缓存键必须包含租户、主体、资源、动作与相关版本；某次撤权提交之后才开始的请求不得命中旧允许结果，已经开始的请求允许按旧快照完成。
3. 策略批量替换必须原子且先检查引用和类型，非法版本保留原策略；重复版本内容冲突要拒绝。实现可解释判定树和有限属性域的旧新策略差分，输出旧拒绝新允许的具体反例。

必须覆盖的验收场景：缺字段取反、跨租户同名主体、缓存期间属性变化、策略替换与读取并发、冲突版本及布尔嵌套；用小域穷举核对差分并以进程屏障检验撤权边界。

交付源代码、README、样例及自动化测试。提供 python -m solution --input cases.json --output result.json 和 python -m unittest discover -s tests -v 两个入口；cases.json可引用项目内源文件或二进制样例。输入输出schema、错误码及未写明的非安全性细节自行设计并完整说明，不能放宽上述要求。测试必须断言具体结果、状态或证据，不能只打印成功；固定种子可重放。所有操作局限在项目测试目录和本机模拟服务。
